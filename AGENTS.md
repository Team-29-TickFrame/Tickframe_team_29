# AGENTS.md

## Purpose

This file provides repository-level guidance for coding agents working in Tickframe.

## Agent workflow

- Prefer issue-linked, milestone-scoped changes.
- Keep PRs focused on one task where practical.
- Reference and preserve maintained docs when changing behavior or process.
- Update affected public documentation when setup/access/workflow changes.

## Key documentation entry points

- `README.md`
- `docs/roadmap.md`
- `docs/development-process.md`
- `docs/testing.md`
- `docs/user-acceptance-tests.md`
- `docs/architecture/README.md`

## Safety rules

- Do not commit secrets, credentials, private access instructions, or customer-identifying private evidence.
- Keep private recording links/timecodes in private submission channels only.
- Respect protected-branch workflow and review requirements.
